# UI/UX Design Skill & Guidelines

## Purpose
Directs visual styling, hierarchy, typography, colors, and motion for a developer-first platform aesthetic like roadmap.sh.

## Design System Principles
1. **Palette**:
   - Dark background base: `zinc-950` (#09090b) with elevated surfaces `zinc-900/80` and `zinc-900/60`.
   - Subtle high-precision borders: `zinc-800` (#27272a).
   - Brand Accent: Violet / Indigo (`indigo-500` / `indigo-600`) with glowing backdrop blurs.
   - Status indicators: Emerald (`emerald-400` / `emerald-500`) for completed milestones, Amber (`amber-400`) for intermediate.
2. **Typography & Hierarchy**:
   - Crisp sans-serif (`Geist` / modern system fonts) with tight letter spacing (`tracking-tight`) on headings.
   - Distinct badges (`uppercase`, `text-[10px]`, `font-bold`) for category tags and difficulty levels.
3. **Interactive Visual Feedback**:
   - Hover scaling (`hover:scale-102`) and border illumination on interactive cards.
   - Clean, readable side drawers for topic details that smoothly slide in without blocking navigation.
   - High-contrast nodes on the canvas that clearly delineate milestones, subtopics, and completion checkmarks.
